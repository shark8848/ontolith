## 1. 部署拓扑与升级方式

- 拓扑与 REL-PROD-0001 一致（单节点：网关 `127.0.0.1:8080` + gRPC `127.0.0.1:50051`、
  管理面 `127.0.0.1:9091`；RocksDB 数据目录 `/home/ontolith/prod/data` 不动）。
- 本环境为容器（无 systemd/sudo），沿用守护进程模式（`scripts/ontolith-prod-ctl.sh`）。
- 升级：`cargo build --release -p ontolith-server --bin ontolith-server --bin ontolith-management-server`
  → 替换 `prod/bin/`；旧二进制（2026-08-10 构建）已备份至
  `prod/bin/rollback-2026-08-10/`（含当时的 `binary-fingerprints-2026-08-10.txt`）。

## 2. 本次发布覆盖的新能力（相对旧二进制）

- P1-01 Ontology 载荷联动（推理输入合并，server 侧 env 接线；未启用 env 则默认行为不变）
- P2-05 管理面备份调度（管理面 `ONTOLITH_BACKUP_DIR`/`ONTOLITH_BACKUP_INTERVAL_SECONDS` 契约）
- WBS-02 JSON-LD 导入扩展（`@reverse`/`@nest`/`@included`/`@json`/远程 `@context`/`@propagate`/`@import`；
  `ONTOLITH_JSONLD_REMOTE_CONTEXT=1` 启用远程加载）
- P2-04 Async 索引维护（`ONTOLITH_INDEX_MAINTENANCE=async`）
- RemoteProvider + ANN（`ONTOLITH_SEMANTIC_EMBEDDING_*`，未配置回退 feature-hash）
- 租户管理（网关承载 `/admin/tenants*`，RocksDB 持久注册表；`/health` 显示 `tenants=on`）

以上 env 均未在本次刷新中变更生产配置（保持 REL-PROD-0001 基线），默认行为与旧版一致。
