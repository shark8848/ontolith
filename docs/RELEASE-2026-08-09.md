## 1. 部署拓扑与约束

- 单节点生产运行：`127.0.0.1:8080`（HTTP 网关）、`127.0.0.1:50051`（gRPC）、
  `127.0.0.1:9091`（管理面）。
- 本环境为容器（无 systemd session bus、无 sudo，`systemctl` 不可用），故采用
  **守护进程模式**部署（`scripts/ontolith-prod-ctl.sh`，PID 文件 + `setsid` 脱离会话）；
  真机发布仍按 [L7 §1.2](./L7-release-rollback.md) 使用随仓 systemd unit
  （`deployments/ontolith-server.service` / `ontolith-management-server.service`）。
- 生产根目录：`/home/ontolith/prod/`（**已入 `.gitignore`，密钥不入库**）。
- SLO timers（`install-ontolith-slo-timers.sh`）依赖 systemd，本容器跳过；
  真机部署时按手册启用。

## 2. 生产配置

- 网关：`ONTOLITH_BIND=127.0.0.1:8080`、`ONTOLITH_GRPC_BIND=127.0.0.1:50051`、
  `ONTOLITH_STORAGE=rocksdb`、`ONTOLITH_DATA_DIR=/home/ontolith/prod/data`、
  `ONTOLITH_AUTH_MODE=enforced`（`X-API-Key` + `X-Ontolith-Tenant` + `X-Ontolith-User`）。
- 管理面：`ONTOLITH_MANAGEMENT_BIND=127.0.0.1:9091`、`ONTOLITH_STORAGE=memory`、
  `ONTOLITH_AUTH_MODE=enforced`、`ONTOLITH_AUDIT_PATH=/home/ontolith/prod/data/audit.jsonl`。
- 审计：RocksDB 数据目录 + 管理面 `FileAuditLog` JSONL（哈希链，`prev` 字段）。
